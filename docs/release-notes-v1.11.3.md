# Release notes — v1.11.3

Пополнение кредитки сверх лимита, человеческие тексты ошибок API и точнее разбор банковских уведомлений на Android. Полный список — [CHANGELOG.md](../CHANGELOG.md).

---

> **Сделайте бэкап** `data/buhgalter.db` и каталога `backups/` перед обновлением. Миграций БД в этом релизе нет.

## Кредитная карта: пополнение сверх лимита

Раньше перевод **на** кредитку отклонялся, если сумма была хотя бы на копейку больше остатка долга (`лимит − баланс`). Банк так не делает: переплату можно положить на карту.

Теперь сумма перевода не ограничена лимитом. Пример: лимит 130 000, на карте 0, перевели 140 000 — баланс 140 000, в блоке «Кредитные средства» тоже 140 000. Кнопка **«Весь лимит»** по-прежнему подставляет только остаток долга. И на вебе, и на Android.

## Ошибки без сырого кода

Если сервер отвечал кодом вроде `ERR_CREDIT_CARD_PAYMENT_EXCEEDS_LIMIT`, в тосте и в форме иногда показывалась эта строка как есть. Теперь у каждого кода API есть текст на русском и английском. Если перевода нет, UI показывает общее «Ошибка», а не `ERR_…`.

## Перехват уведомлений (Android)

**«Возврат».** Пуш про возврат денег создаёт черновик **дохода**, магазин берётся из текста после суммы. Формулировки отмены покупки по-прежнему не считаются возвратом.

**Категория черновика.** Категория и подкатегория подставляются по истории операций **того же типа** (доход к доходу, расход к расходу): сначала по магазину, если его нет в справочнике — по описанию или метке операции (например «Выплата процентов»).

## Обновление

**Сервер:** миграций нет. Замените бинарник или образ и перезапустите. Поведение API: перевод на кредитную карту больше не отклоняется из‑за превышения лимита. Обновлены строки ошибок (`server/locales`) и каталог Android UI.

**Веб:** встроен в бинарник/образ сервера, обновляется вместе с ним.

**Android:** новый APK из [Releases](https://github.com/kai-zer-ru/buhgalter/releases) или из попапа «Версии». Исправления перехвата — только в новом APK; пополнение кредитки и тексты ошибок — и в APK, и на сервере (обновите оба).

## Для разработчиков

- OpenAPI / версия сборки **1.11.3**. Схема БД не менялась.

- `formatApiError` / `isRawErrorCode`: не показывать строку вида `ERR_…`. Каталоги: `server/locales/{ru,en}.json` и `errors.{code}` в web и `android/ui`.

- Перехват: «Возврат» → income; категория черновика — история того же типа (merchant, иначе описание/метка).
- Тесты: `TestCreditCardPaymentMayExceedLimit`, `formatApiError` (сырой код), Playwright `credit-card` (оплата сверх лимита), `credits-principal-income` — локализованный `message`.
