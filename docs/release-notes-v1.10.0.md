## Сканер чеков

Кассовый чек РФ (QR 54-ФЗ) превращается в расходы по позициям или прикрепляется к уже записанной покупке. Работает в вебе и в Android.

### Включение

Модуль включает **администратор инстанса**, нужны оба условия:

1. **Админка → модули** — флаг «Сканер чеков» (`receipt_scanner`, по умолчанию выключен).
2. **Админка → API чеков** — токен [proverkacheka.com](https://proverkacheka.com/). Значение после сохранения не показывается, видно только «настроено». Перезапуск не нужен.

Состав чека даёт proverkacheka, токен один на весь сервер. Сколько чеков можно запросить, задаёт тариф провайдера. Как получить токен — в [README](../README.md#сканер-чеков-токен-proverkacheka). Без токена кнопки «Чек» нет.

### Новый чек

Кнопка **«Чек»** — на главной, в операциях и на странице счёта. QR читается **на устройстве**: камерой, со снимка или из файла. На сервер уходит строка QR, не картинка. Фото нигде не хранится.

На экране подтверждения:

- **счёт** для всех создаваемых расходов;
- список позиций: каждую можно выключить, у каждой своя категория и подкатегория (подкатегорию можно создать прямо там);
- **«Общая категория»** и кнопка **«Проставить без категории»** — подставляет общую категорию всем включённым строкам, где категория ещё не выбрана. Уже выбранные вручную не трогает. Удобно для смешанного чека: сначала массово продукты, потом вручную лекарства.

Сохранить можно, когда у каждой включённой строки есть категория. Каждая позиция становится отдельным расходом. Магазин берётся из того же каталога, что у ручной операции: по имени или алиасу, второй такой же не создаётся. Тот же чек второй раз не импортируется.

### Прикрепить к существующей покупке

В меню строки расхода — **«Прикрепить чек»**. Новых операций не создаётся: чек связывается с этим расходом, категории расписываются по позициям. По умолчанию у позиций стоит категория самой операции.

Сумма операции и итог чека сверяются до копейки. Не совпало — приложение спросит «Добавить всё равно» или «Отмена». Магазин подставляется, только если у расхода его ещё не было. Подкатегории позиций прикреплённого чека видны в статистике по подкатегориям.

**«Открепить чек»** — в меню строки или в просмотре чека. Магазин операции остаётся.

### В журнале

У операций из чека — иконка чека. По нажатию открывается чек целиком, текущая позиция подсвечена, у каждой строки видна категория. Колонка категории у всех операций одного чека: одна категория — она (и подкатегория, если она тоже одна), разные — все через запятую.

Блок **«По магазинам»** на статистике считает и ручные расходы, и чеки по каталогу магазинов.

В Android сканер работает только при связи с сервером.

На публичном демо-стенде сканер выключен: лимита провайдера не хватает на общий стенд.

Подробнее — [receipt-scanner.md](receipt-scanner.md), [android-client-receipts.md](android-client-receipts.md).

## Android: демо-режим

Посмотреть учёт можно без своего сервера. Кнопка **«Войти в демо-режим»** — на экране адреса сервера и на выборе способа входа. Одно нажатие — и вы на публичном стенде `buhgalter-demo.kai-zer.ru` под пользователем `demo`. Данные на стенде общие.

Если в приложении уже сохранён свой сервер, сначала будет вопрос, заменить ли его. Если стенд недоступен, прежний адрес остаётся.

Подробнее — [android-demo-login.md](../roadmap/android-demo-login.md).

## Платёж по кредиту: изменить время

У операции, связанной с платежом по кредиту, полное редактирование по-прежнему закрыто. В меню строки теперь **«Изменить время»** вместо пунктов подписки. Меняются только часы и минуты, день операции, сумма и время автосписания кредита остаются. Web и Android.

Подробнее — [transactions-display.md](transactions-display.md#редактирование-дохода-и-расхода).

## Бюджет: копирование на следующий месяц

Тумблер **«Копировать на следующий месяц»** у уже наступившего месяца при сохранении сразу пишет **только следующий** месяц и выключает копирование у него. Месяц через один появляется 1-го числа, если у следующего копирование включено. Просмотр бюджета и сводки ничего не создаёт.

Подробнее — [budget.md](budget.md).

## Исправления

**Android**

- Системный «Назад» после перехода из пуша или по внешней ссылке открывает главную, а не закрывает приложение.
- Главная без сети больше не прячет уже показанную сводку за заглушкой «Сервер недоступен» и не дублирует toast. Внизу — полоска «Нет соединения».

**Web и Android**

- Удаление магазина убирает строку на месте: список не перезагружается, поиск и прокрутка сохраняются.

**Сервер**

- Предупреждения части запросов (привязки банковских уведомлений, настройки уведомлений, удаление данных, импорт) теперь пишутся в `logs/app.log`. Раньше они шли только в stdout, и причину ошибки 500 в логе не было видно.

## Обновление

**Сервер / Docker:** бэкап → замена бинарника или `docker compose pull && up -d`. Миграции `057`–`062` применятся при старте. Для сканера чеков, «Изменить время» у платежа кредита и нового копирования бюджета нужен сервер **≥ 1.10.0**. Версия сборки **1.10.0**.

**Веб:** встроен в бинарник/образ сервера.

**Android:** новый APK из [Releases](https://github.com/kai-zer-ru/buhgalter/releases) или из попапа «Версии» — сканер чеков, демо-вход, «Изменить время», «Назад» и главная без сети.
