# Release notes — v1.10.1

Исправления Android после 1.10.0. Полный список — [CHANGELOG.md](../CHANGELOG.md).

---

> **Сделайте бэкап** `data/buhgalter.db` и каталога `backups/` перед обновлением. Миграций БД в этом релизе нет.

## Окно «Изменить время» у края экрана

У платежа по кредиту в меню строки есть «Изменить время». На главной, в операциях и на странице счёта окно открывалось в самом низу длинной страницы: казалось, что ничего не произошло, пока не прокрутишь до конца.

Теперь окно, как и остальные модальные окна приложения, открывается у нижнего края экрана поверх страницы. Pull-to-refresh работает как раньше.

## Выбор времени по тапу

Системный выбор времени открывался только по иконке часов справа в поле. Теперь он открывается по тапу в любом месте поля. Это касается всех полей времени Android: «Изменить время», время в операции, переводе и долге, время автосписания кредита (в карточке и при создании), график платежей кредита, подписки, периодические операции, уведомления и бэкапы.

## Обновление

**Сервер:** миграций нет. Замените бинарник или образ и перезапустите; сервер и веб в этом релизе не менялись, сменилась только версия сборки.

**Веб:** встроен в бинарник/образ сервера, изменений нет.

**Android:** новый APK из [Releases](https://github.com/kai-zer-ru/buhgalter/releases) или из попапа «Версии». Все исправления этого релиза — в APK.

## Для разработчиков

- OpenAPI / версия сборки **1.10.1**. API и схема БД не менялись.
- Android `ModalShell` переносит оверлей в `document.body` (`use:portal`, как в web).
- `PullToRefresh`: `transform` и `will-change` у контента только при ненулевом сдвиге (`ptrContentTransform` в `$lib/pull-to-refresh.ts`).
- `$lib/actions/native-time-picker.ts`: `use:nativeTimePicker` на каждом `<input type="time">` Android UI, `click` → `showPicker()`.
- Тесты vitest: `native-time-picker.test.ts`, `pull-to-refresh.test.ts`, `android-ui-invariants.test.ts` (source-scan: портал в `ModalShell`, action на всех полях времени).
- Документация: [android-client-ui.md](android-client-ui.md#модальные-окна-modalshell), [README.md](../README.md).
