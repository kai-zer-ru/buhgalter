## Нетто-капитал и графики статистики

На `/stats` появился блок **нетто-капитала**: активы (наличные/банки + «мне должны») минус обязательства (долги, остаток кредитов, задолженность по кредиткам). Ряд по месяцам пересчитывается из операций (отдельных снапшотов в БД нет).

- **Web:** line chart нетто, столбцы доходов/расходов, donut расходов по категориям (Chart.js); таблицы как раньше.
- **Android:** карточка текущего нетто + расшифровка + список по месяцам **без** графиков.

Блок скрыт, если в фильтрах выбраны тип, счёт или категория.

API: `GET /api/v1/stats/net-worth`. Подробнее — [ui-stats.md](ui-stats.md), [stats-charts-net-worth.md](../roadmap/stats-charts-net-worth.md).

## Правила категорий и очередь «Разобрать»

Постоянные правила пользователя (не путать с разовым маппингом при файловом импорте):

| Тип | Пример |
|-----|--------|
| Категория → счёт | «Транспорт / Автобус» → счёт «Наличные» в форме |
| Текст → категория | описание содержит «яндекс» → категория «Транспорт» |

- Экран правил: web — «Прочее» → `/category-rules`; Android — drawer → «Правила категорий».
- Очередь операций **без категории**: «Разобрать» (пункт и badge только при `inbox_count > 0`); из очереди можно назначить категорию и сохранить «всегда так» как правило.
- В форме операции — подсказка / автоподстановка (`POST /category-rules/evaluate`); при создании на сервере, если подходит ровно одно text-правило, категория проставляется молча.

Подробнее — [category-rules.md](category-rules.md).

## Перехват уведомлений (Android)

- Привязки банк/карта→счёт хранятся **на сервере** и подтягиваются при входе и при сохранении настроек — после переустановки APK настройки не теряются.
- После переустановки ручной sync больше не «пережёвывает» десятки тысяч событий ленты изменений: warm только выставляет watermark; полный replay не гоняется при каждом старте.
- SMS из штатного «Сообщения» и OEM снова попадают в черновики; кнопки создания операции/перевода в карточке черновика — на всю ширину.

## Балансы, вход и мелочи UI

- После создания, правки или удаления операции/перевода балансы и списки на открытых экранах (web и Android) обновляются сразу, без ожидания SWR-cooldown.
- Deep link вроде `/budget` → логин → возврат на исходный URL (`?next=`), а не на главную.
- Ссылки из уведомлений `/subscriptions/{id}` открывают редактирование подписки (редирект на `?edit=`), без циклической перезагрузки.
- Выход из профиля больше не показывает toast «Требуется авторизация».
- Бюджет: удалённая строка будущего месяца не появляется снова из‑за `copy_forward`.
- Android: сетевые ошибки вроде `Host unreachable` показываются по-человечески, не сырым английским текстом.

## Обновление

**Сервер / Docker:** бэкап → замена бинарника или `docker compose pull && up -d`. Миграции `053` (bindings перехвата) и `054` (`category_rules`) применятся при старте. Нужен сервер **v1.8.0** для нетто, правил, inbox и серверных bindings.

**Android:** установите новый APK из [Releases](https://github.com/kai-zer-ru/buhgalter/releases) или из попапа «Версии». Нетто, правила/inbox, sync bindings и фиксы SMS/sync — в APK; сервер тоже должен быть ≥ 1.8.0.

**Веб:** встроен в бинарник/образ сервера.
