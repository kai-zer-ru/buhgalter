# Release notes — v1.11.2

Исправления перехвата уведомлений, сканера чеков, бейджа кредита и бюджета, а также более спокойный интерфейс веба и Android. Полный список — [CHANGELOG.md](../CHANGELOG.md).

---

> **Сделайте бэкап** `data/buhgalter.db` и каталога `backups/` перед обновлением. Миграций БД в этом релизе нет.

## Уведомления банков

**Ozon Банк.** В пушах Ozon Банка тысячи отделяются узким неразрывным пробелом. Из-за него черновик получал только последние цифры: покупка на 3 073 ₽ превращалась в 73 ₽. Теперь такие пробелы распознаются, сумма приходит целиком. Название «Ozon Банк» из заголовка пуша больше не подставляется как магазин.

**WB Банк.** Доход «Выплата процентов» попадал в описание черновика как «а процентов». Теперь в описании полная метка операции.

## Сканер чеков

Пока камера искала QR-код, кнопки «Остановить» и «Загрузить фото» были неактивны: нельзя было ни выключить камеру, ни выбрать снимок чека из галереи. Теперь обе кнопки работают при включённой камере, а выбор фото сам её останавливает. Исправлено и на Android, и в вебе (импорт чека и прикрепление чека к операции).

## Дата ближайшего платежа по кредиту

Бейдж на карточке кредита считал дни по UTC. В часовом поясе восточнее UTC платёж на завтра показывался как «сегодня», и у всех кредитов срок сдвигался на день. Теперь день считается по часовому поясу пользователя.

## Бюджет без сброса прокрутки

«Копировать на следующий месяц» в меню бюджета, сохранение и удаление перерисовывали страницу целиком и возвращали её наверх. Теперь список обновляется на месте, прокрутка сохраняется.

В форме бюджета переключатели «Активен» и «Копировать на следующий месяц» стоят в один ряд, без поясняющего текста. В вебе поля формы выровнены в две колонки.

## Интерфейс

- **Кнопки без яркой заливки.** Основные кнопки — тональные «таблетки» в цвет темы, опасные — такие же в красном. Приглушены тумблеры, выбранные вкладки и переключатели вариантов. Правила — в [ui-visual-style.md](ui-visual-style.md#кнопки).
- **«+ Добавить» везде.** Кнопка создания в шапке списков называется одинаково: счета, кредиты, подписки, периодические операции, бюджет, шаблоны, правила категорий.
- **Заголовки групп одного вида.** Только название, без счётчика и подсказки.
- **Периодические операции** разделены на «Активные» и «Неактивные».
- **Меньше подсказок.** Убраны пояснения, которые повторяли очевидное: периодические операции, шаблоны, категории, магазины, теги, правила категорий. На Android ещё «Черновики», «Уведомления банков», «Сервер» и «Безопасность». Предупреждения о последствиях действий остались.

## Обновление

**Сервер:** миграций нет. Замените бинарник или образ и перезапустите. API не менялся; обновлены строки Android UI, которые сервер отдаёт клиенту.

**Веб:** встроен в бинарник/образ сервера, обновляется вместе с ним.

**Android:** новый APK из [Releases](https://github.com/kai-zer-ru/buhgalter/releases) или из попапа «Версии». Исправления перехвата уведомлений и сканера — только в новом APK.

## Для разработчиков

- OpenAPI / версия сборки **1.11.2**. API и схема БД не менялись.
- Парсеры перехвата (`android/ui/src/lib/android/notification-intercept/parsers.ts`): нормализация U+2007 / U+2009 / U+202F / U+2060; доход — контрагент → магазин из SMS → заголовок → метка операции.
- `daysUntilApiDate(apiDate, tz, now)` в `$lib/dates.ts` обоих клиентов: разница в календарных днях по часовому поясу пользователя.
- Стили: токены `--primary-ink` и `--switch-knob`, классы `.btn-add` и `.btn-icon-soft` в `routes/layout.css` обоих клиентов.
- Бюджет: после мутаций `loadAll({ background: true })` — без размонтирования `PageLoadGate`.
- Ключи i18n: `common.add`, `recurring.group.active`, `recurring.group.inactive`.
- Тесты: vitest `parsers.test.ts`, `dates.test.ts`; Playwright `receipt-import.spec.ts` (фейковая камера), обновлены `budget`, `z-category-rules`, `coverage-gaps`, `credits-principal-income`.
- Документация: [ui-visual-style.md](ui-visual-style.md), [android-client-ui.md](android-client-ui.md), [android-client-receipts.md](android-client-receipts.md), [README.md](../README.md).
