# Release notes — v1.5.0

Краткая сводка для пользователей и администраторов. Полный список изменений — [CHANGELOG.md](../CHANGELOG.md).

## Подписки

Отдельный раздел для регулярных сервисов (не путать с периодическими операциями вроде зарплаты):

- сводка «в месяц» / «в год» и ближайшие списания;
- системная категория «Подписки»;
- поиск и привязка прошлых операций, «Сделать подпиской» из журнала;
- уведомления о списании.

Плановый остаток на главной (`forecast_balance`) теперь учитывает активные **подписки** и **периодические** операции текущего месяца. Подпись строки зависит от состава: «С учётом плановых», «С учётом подписок» или «С учётом плановых и подписок».

Подробнее — [subscriptions.md](subscriptions.md).

## Магазины и теги

На операции можно указать **магазин** из справочника (или создать по имени) и несколько **тегов**. В списке операций — фильтры по магазину и тегу. Описание / комментарий по-прежнему одно поле.

Справочники — в настройках. Модуль можно выключить флагом `merchants_tags` (см. ниже).

## Шаблоны операций

Именованные пресеты частых расходов, доходов и переводов:

- управление в **Настройки → Шаблоны**;
- на главной — сворачиваемый блок; тап открывает форму с подставленными полями;
- из журнала — «Сохранить как шаблон»;
- с экрана настроек — сразу создать операцию по шаблону.

Без автосоздания по расписанию (для этого — периодические и подписки).

## Перехват уведомлений банка (Android)

С явного разрешения приложение читает push банков и предлагает **черновик** расхода или дохода (сумма, счёт, магазин). Операция создаётся только после подтверждения в форме.

- покупки → расход; входящие / проценты / пополнения → доход;
- OTP, баланс, отказы — игнор;
- отмена покупки снимает соответствующий черновик;
- при открытии черновика категория/подкатегория подставляются по истории того же магазина, если он уже в справочнике.

Настройки: **Настройки → Уведомления банка**. На MIUI/HyperOS обычно нужны автозапуск и отключение оптимизации батареи, иначе слушатель не живёт в фоне.

Подробнее — [android-client-platform.md](android-client-platform.md).

## Модули в админке

Администратор включает и выключает опциональные разделы (**Админка → Модули**, только web): долги, кредиты, бюджет, подписки, магазины/теги, шаблоны, уведомления и др. Выключенный модуль скрыт в меню web и Android; API отвечает `404` (`FEATURE_DISABLED`). Данные в БД не удаляются.

Подробнее — [feature-toggles.md](feature-toggles.md).

### Breaking: регистрация

Поле `registration_enabled` **убрано** из `GET/PUT /api/v1/admin/settings`.

- Управление — флаг `registration` в `GET/PUT /api/v1/admin/features`.
- Для страницы входа по-прежнему смотрите `registration_enabled` в `GET /setup/status`.
- При миграции текущее значение из `system_settings` переносится в `feature_flags`.

## Главная и форма операции

- Форма: спойлер «Время, комментарий, магазин, теги»; магазин и подкатегория — с быстрым созданием по имени.
- Виджеты шаблонов и бюджета на главной — в сворачиваемых секциях.

## Обновление

**Сервер / Docker:** бэкап → замена бинарника или `docker compose pull && up -d`. При старте применятся миграции `043`–`050`.

**Android:** установите новый APK поверх старого или из попапа «Версии» в боковом меню (если приложение отстаёт от сервера по мажор/минор). Для перехвата банковских push — выдать доступ к уведомлениям и при необходимости настроить автозапуск.
