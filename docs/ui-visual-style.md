# UI — визуальный стиль веба

Единый вид страниц веб-клиента: группы с заголовком и подсказкой, списки одной карточкой, бейджи статуса. Документ описывает образец, по которому переделываются экраны (ROADMAP v1.11.0). Android-клиент (`android/ui`) следует тому же стилю: классы в его `routes/layout.css`, `GroupHeading` — своя копия; платформенные правила (формы на весь экран, офлайн) — в [android-client-ui.md](android-client-ui.md).

---

## Страница

- Сверху `BackLink`, затем `h1`. Кнопка создания — в шапке рядом с `h1` (`SectionHeader` с `actions`), см. [ui-navigation.md](ui-navigation.md).
- Корень страницы — `space-y-6`: навигация, шапка и контент. Блоки контента разделены отступом `space-y-8`, в том числе сводная карточка над списком и спойлеры, сгруппированные под подзаголовком («Личные» на главной). Внутри блока — `space-y-3`. Связанные карточки одной сводки (долги и статистика должника) — `space-y-4`.
- В карточке-форме разделы — `space-y-6` с `border-t pt-6`, внутри раздела — `space-y-4` (профиль, пароль).
- Контент страницы — на всю ширину, как и общие блоки под ним (поддержка проекта в админке), чтобы края совпадали. Короткие формы-карточки ставятся рядом: `grid gap-4 lg:grid-cols-2`, футер с кнопками — `mt-auto`, чтобы низ карточек совпал. Исключение — одиночная форма без соседних блоков (профиль, пароль): `max-w-2xl` / `max-w-lg`.

## Группа

- Заголовок группы — `GroupHeading` (`$lib/components/GroupHeading.svelte`): `h2` + серая подсказка одной фразой. Подсказка объясняет, что делает блок или как с ним работать, а не повторяет заголовок.
- Счётчик — в заголовке: «Магазины · 5».
- Кнопка, относящаяся только к группе (например «Создать приглашение»), стоит справа от `GroupHeading`.

## Карточка-форма

- `.card` с заголовком (`h2`, `font-semibold`) и подсказкой сверху.
- Поля — с подписью над полем (`label`), не только плейсхолдер. Подпись — класс `.field-label` (как у `Select`, `Combobox`, `DateTimePicker`), без своих цветов и размеров. Пары коротких полей — `grid sm:grid-cols-2`.
- Разделы внутри одной формы отделены `border-t pt-6`.
- Действия — в футере карточки: `border-t pt-4`, справа основная кнопка, слева второстепенная (`sm:mr-auto`).
- Одна кнопка сохранения на блок. Общей «Сохранить всё» нет.
- Для блока с раскрытием (уведомления) — `SettingsPanel` (`$lib/settings/SettingsPanel.svelte`): заголовок, подсказка и бейдж в шапке.

## Список

- Контейнер — `.card list-divided p-0 sm:p-0`: строки через тонкий разделитель (`.list-divided` в `routes/layout.css`).
- Строка: значок или иконка (40px) → название (`font-medium`) и серая строка деталей (`text-xs`) → справа сумма или бейдж → меню «⋯» ([ui-row-actions.md](ui-row-actions.md)).
- Поиск по списку — первой строкой внутри карточки. «Ничего не найдено» — тоже внутри карточки.
- Сортировка перетаскиванием — ручка `.list-drag-handle`; линия вставки — `box-shadow: inset 0 2px 0 var(--primary)` на целевой строке.
- Кликабельная строка — `button.list-row-button` (подсветка при наведении).
- Таблица остаётся там, где это данные с колонками (пользователи, бэкапы, диагностика): та же карточка без отступов, шапка мелким капсом. На мобильном — строки `list-divided`.

## Сводки и таблицы

- Сводка из нескольких чисел — `.card overflow-hidden p-0 sm:p-0` + `.stat-grid grid-cols-2 md:grid-cols-3`: плитки через тонкие линии, подпись `.stat-label`, значение `.stat-value`. Доход — `--primary`, расход и «я должен» — `--danger`. Примеры: `DebtSummaryCard`, `TransactionContextStats`, сводка подписок, факты кредита.
- Таблица — `<table class="data-table …">` в `.card p-0`: шапка мелким капсом, строки через линию, подсветка при наведении. Отступы ячеек (первая и последняя колонки — `1.25rem`, вертикаль) заданы в `layout.css` **вне** `@layer`, чтобы перебить утилиты вроде `p-3` в разметке.
- Строка списка сущности (кредит) кликабельна целиком и ведёт на её страницу; ссылка на названии остаётся для клавиатуры, клики по вложенным ссылкам и кнопкам обработчик строки пропускает. На мобильном — `.list-divided` со строками `<article class="p-4">` вместо обведённых карточек (в Android компактный `TransactionList` — всегда так).
- Заголовок блока со списком или графиком — `GroupHeading` над карточкой, не `h2` внутри неё. Исключение — статистика, где e2e ищет карточку по заголовку.

## Бейджи и цвета

- `.badge` — нейтральный, `.badge-success` — включено / главное / задано. Предупреждение (не настроено, на проверке) — цвет `--warning`, опасное (заблокирован, бессрочный токен) — `--danger`, фон `color-mix(… 12–14%)`.
- Статус показывается бейджем в заголовке блока, а не строкой «Статус: …» внизу.

## Выбор из 2–3 вариантов

- `.segmented` (`routes/layout.css`) вместо выпадающего списка: кнопки с `role="radio"` и `aria-checked`, контейнер `role="radiogroup"`. Если тесты ищут кнопки по роли `button` (тип счёта), — обычные кнопки с `aria-pressed`. Примеры: тема и стиль в профиле, тип шаблона, тип правила.
- Включено / выключено — `ToggleSwitch` справа от подписи, не чекбокс.

## Спойлеры и публичные экраны

- `CollapsibleSection` и `AccountGroupPanel`: заголовок `text-base font-semibold`, счётчик «· N». Вложенные `<details>` (плановые / прошлые операции) — `summary` со стрелкой `.spoiler-chevron`, она поворачивается у открытого.
- Вход, регистрация, выбор сервера, вход по паролю или токену — карточка с `AuthBrand` (значок, «Бухгалтер», подзаголовок) над заголовком.
- Выпадающие списки при открытии ставят фокус с `preventScroll: true`, иначе страница прыгает к полю поиска.

## Опасные действия

- Отдельная группа «Опасная зона» внизу страницы: карточка с красноватой рамкой (`color-mix(in srgb, var(--danger) 40%, var(--border))`), пояснение и `btn-danger` справа.

## Хаб разделов (Android)

- `SectionNavHub` (настройки, админка): карточка `list-divided`, у пункта значок 40px, название и серая подсказка, справа шеврон. Значок и подсказка — необязательные `iconPath` и `hintKey` в `AndroidNavItem` (`$lib/android/nav-items.ts`); drawer их не использует.
