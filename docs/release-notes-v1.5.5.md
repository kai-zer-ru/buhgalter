## Черновики перевода (Android)

Пара «списание + пополнение» с одной суммой больше не размножается на три карточки. На экране одна карточка **«Возможный перевод»**:

- **Создать перевод** — основная кнопка, открывает форму перевода;
- **Как две операции** — разъединяет пару, если это не перевод между своими счетами;
- **Удалить оба** — снять оба черновика без операции.

Счётчик в боковом меню и баннер на главной считают **карточки** (пара = 1), а не сырые уведомления.

Создание и удаление больше не зависают: справочники счетов грузятся в фоне, форма перевода не крутит бесконечный цикл.

Подробнее — [android-client-platform.md](android-client-platform.md), [roadmap/notification-intercept.md](../roadmap/notification-intercept.md).

## Обновление

**Сервер / Docker:** бэкап → замена бинарника или `docker compose pull && up -d`. Новых миграций БД нет. API не менялся.

**Android:** установите новый APK поверх старого или из попапа «Версии» в боковом меню. Исправления черновиков — **только в APK**; сервер **v1.5.4** достаточен, **v1.5.5** — тот же API.
