Краткая сводка для пользователей и администраторов. Полный список изменений — [CHANGELOG.md](../CHANGELOG.md).

> **ОБЯЗАТЕЛЬНО СДЕЛАЙТЕ БЕКАП!** Перед обновлением сервера сохраните копию `data/buhgalter.db` и каталога `backups/`. Новых миграций БД в этом релизе нет. При старте сервер один раз выравнивает категорию у уже привязанных к графику платежей → системная «Кредиты».

## Оплата кредита из журнала и формы

Расход можно связать с графиком кредита так же, как операцию с подпиской:

- в форме расхода выбирается системная категория **«Кредиты»** — вместо подкатегорий показывается список **активных кредитов**;
- сохранение с выбранным кредитом оплачивает ближайший неоплаченный платёж графика;
- в журнале — **«Сделать платежом по кредиту»** для уже созданного расхода (импорт, перехват, ручной ввод);
- магазин, теги и описание в этой форме скрыты; время сразу под датой.

Оплата с карточки кредита и автосписание не менялись. Подробнее — [credit-payment-link.md](../roadmap/credit-payment-link.md), [ui-credits.md](ui-credits.md).

## Счётчик операций

Перевод в журнале считается **одной** операцией, комиссия перевода в счётчик не входит. То же число в превью импорта (`list_rows` = `valid_rows`) и на Android после синхронизации — без расхождения «веб vs телефон» и «импорт vs главная».

## Перехват уведомлений (Android)

- **Шторка:** после черновика — своё уведомление с **Принять** / **Отклонить** (тумблер «Уведомления в шторке» в настройках банковских уведомлений).
- **Черновики:** без чекбоксов и массового удаления; у карточки перевода — **«Удалить»**, как у остальных.
- **История:** по распарсенной строке — **«Создать операцию»** или **«Создать перевод»** (уникальная пара), чтобы снова оформить после удаления черновика без ручного ввода суммы.
- Каталог банков: **ВБРР**.

Подробнее — [android-client-platform.md](android-client-platform.md), [notification-intercept.md](../roadmap/notification-intercept.md).

## UI Android

Выпадающие списки открываются вниз (вверх — только если у низа экрана нет места) и не прыгают при скролле. Своя цифровая клавиатура больше не уступает место системной при возврате из другого приложения.

## Обновление

**Сервер / Docker:** бэкап → замена бинарника или `docker compose pull && up -d`. Новых миграций БД нет. Привязка операции к кредиту требует сервер **v1.6.0**.

**Android:** установите новый APK поверх старого или из попапа «Версии» в боковом меню. Quick-actions, история и правки черновиков — в APK; привязка к кредиту — сервер **v1.6.0** (или новее).
