## SMS-перехват покупок банка (Android)

К перехвату **push** добавлены входящие **SMS** известных банков: тот же список черновиков, операция создаётся только после подтверждения в форме.

- отдельное разрешение Android на чтение SMS (не нужно становиться приложением SMS по умолчанию);
- сырые SMS остаются на устройстве; на сервер уходит только подтверждённая операция;
- если пришло и push, и SMS об одной покупке — в черновиках одна запись;
- SMS из системного «Сообщения» (заголовок вроде «Ваш Т-Банк») тоже попадают в очередь.

Настройки: **Настройки → Банковские уведомления**. Push по-прежнему основной канал; SMS — опционально.

Подробнее — [android-client-platform.md](android-client-platform.md), [notification-intercept.md](../roadmap/notification-intercept.md).

## Несколько счетов одного банка (Android)

Один банк можно привязать к **нескольким** счетам (например три карты в Т-Банке). Если карта `*XXXX` не сопоставлена, расход пойдёт на первый привязанный счёт этого банка.

## Виджеты (Android)

- суммы скрыты только пока нужен экран PIN; после разблокировки виджеты снова показывают цифры;
- в **Настройки → Безопасность** — опция **«Показывать виджеты при блокировке»** (по умолчанию выкл.);
- «Мои средства»: наличные, банковские карты, кредитные средства; тап открывает список счетов;
- «Скоро»: до пяти ближайших — кредит, долг, плановые, подписки, периодические;
- суммы везде в том же формате, что в приложении (`1 500.00 ₽`).

Подробнее — [android-client-platform.md](android-client-platform.md#home-screen-виджеты).

## Шаблоны операций — отдельная страница

Список шаблонов больше не вкладка настроек, а свой раздел **«Шаблоны операций»** (в вебе — меню «Прочее»; в Android — пункт бокового меню). Старый адрес `/settings/transaction-templates` перенаправляет на новый.

## Клонирование приложения (Android)

Параллельная копия приложения (вторая копия / dual-app у производителя) больше не затирает вход основной установки: у каждой копии свои ключи хранилища и своя сессия.

## Офлайн и справочники

**Android:** после записи операции форма снова со счётом и категорией; категории и счета в офлайне не «ломаются»; кнопка «Вся сумма» в переводе остаётся активной после смены исходящего счёта.

**Веб и Android:** после создания или правки категории / подкатегории список обновляется сразу (не ждёт фонового обновления кеша).

## Плановый остаток и еженедельные подписки

Исправлен расчёт планового остатка на счёте: для подписок с периодом «раз в неделю» учитываются все оставшиеся списания в текущем месяце, а не только ближайшее.

## Обновление

**Сервер / Docker:** бэкап → замена бинарника или `docker compose pull && up -d`. Новых миграций БД нет.

**Android:** установите новый APK поверх старого или из попапа «Версии» в боковом меню. Для SMS-перехвата — выдать разрешение на чтение SMS в **Настройки → Банковские уведомления** (или в системных настройках приложения).
