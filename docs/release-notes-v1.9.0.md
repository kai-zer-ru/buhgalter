## Кнопки в Telegram и MAX

В **Настройки → Уведомления** (только **web**) можно собрать **inline-клавиатуру**:

- **Кнопки по умолчанию** (global) — на каждое исходящее сообщение;
- **кнопки в шаблоне** триггера — отдельно для Telegram и MAX;
- конструктор с drag-and-drop, пресеты по типу шаблона (долги, кредит, бюджет, «Открыть счёт» и др.), предпросмотр и тестовое сообщение с кнопками.

Порядок рядов при отправке: global → шаблон → блок недостатка средств (если он дописан). Ссылки строятся от **внешнего URL** в админке; кнопка без URL после подстановки плейсхолдеров в сообщение не добавляется.

На **Android** страница уведомлений — баннер «Настройте в веб-версии» (каналы, шаблоны и кнопки настраиваются в браузере). Обработка нажатий кнопок (webhook) в этом релизе **не** входит.

Подробнее — [notifications.md](notifications.md), [telegram-max-buttons.md](../roadmap/telegram-max-buttons.md).

## UX polish (web и Android)

- На touch / Android WebView **нет видимых полос прокрутки**; на desktop — тонкие.
- **Потянуть вниз** на списках (Capacitor и web mobile) — soft-обновление текущего экрана (не полный Sync All).
- В профиле — **стиль интерфейса**: «Классика» или «MaterialBased» (хранится локально, не на сервере).

Спека — [ux-polish.md](../roadmap/ux-polish.md). Идёт ручная приёмка (soak); отдельные баги — отдельными коммитами.

## Android: запуск и перехват банковских уведомлений

- Исправлено: приложение **сразу сворачивалось** при запуске (гонка при фоновом подъёме перехвата на HyperOS и др.).
- **Принять** в шторке снова открывает форму операции/перевода с предзаполнением (не создаёт операцию сразу); подтверждение — «Сохранить». **Отклонить** без изменений.
- В поле **Магазин** формы черновика — имя точки, а не почти весь текст push (`MAGNIT GM Petro` вместо `Оплата р Карта … Баланс`).
- Парсер лучше распознаёт **входящие**: ВТБ «Поступление», Сбер SMS «Перевод по СБП», сумму с «р» без кода валюты, last4 из `СЧЁТ5159`.
- В README — раздел про Android 15+ **«Конфиденциальные данные скрыты»** (выключить Enhanced notifications или ADB `RECEIVE_SENSITIVE_NOTIFICATIONS`).

## Мелочи

- Web: кнопка сохранения в настройках уведомлений больше не показывает сырой ключ перевода вместо текста (на Android этой кнопки нет — только баннер).
- У шаблона недостатка средств — `{account_url}` (ссылка на счёт).

## Обновление

**Сервер / Docker:** бэкап → замена бинарника или `docker compose pull && up -d`. Миграция `055` (колонки `keyboard_telegram` / `keyboard_max`) применится при старте. Для кнопок в Telegram/MAX нужен сервер **≥ 1.9.0**.

**Android:** установите новый APK из [Releases](https://github.com/kai-zer-ru/buhgalter/releases) или из попапа «Версии». Фикс сворачивания и шторки, UX polish, парсер и баннер уведомлений — в APK.

**Веб:** встроен в бинарник/образ сервера (кнопки, polish, i18n).

## Для разработчиков

- OpenAPI **1.9.0**: поля `keyboard_telegram` / `keyboard_max` в настройках и шаблонах уведомлений; preview с resolved keyboards; UI payload без клиентского `id` (`toApiKeyboard`).
- `make ui-i18n-check` — литеральные ключи из UI должны быть в ru и en.
