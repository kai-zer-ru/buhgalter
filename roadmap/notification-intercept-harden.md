# v1.9.1 — Улучшение перехвата уведомлений (harden)

Статус: **реализовано**. Пункт в [ROADMAP](../ROADMAP.md#v191).

Доработка пайплайна [notification-intercept.md](notification-intercept.md): меньше ложных уведомлений в шторке, корректный разбор реальных операций (в т.ч. WB Кошелёк / СБП).

## Принцип (мнение владельца)

**Черновики и уведомления бухгалтера в шторке — одна логика распознавания.**

Сейчас расхождение:

| Слой | Когда срабатывает | Эвристика суммы |
|------|-------------------|-----------------|
| JS-парсер → черновик | `parseBankNotification` после allowlist | строгие `INCOME_RE` / `PURCHASE_HINT` / валюта |
| Native provisional → шторка | **сразу** при постановке в очередь allowlist-пакета | отдельный regex, валюта **опциональна** |

Итог: в шторке появляется «бухгалтер», даже когда черновик **не** создаётся («в allowlist, но не распознано»).

Целевое поведение: в шторке — только то, что прошло бы в очередь черновиков (после успешного parse, или provisional с **тем же** gate и немедленной отменой при `null`).

## Переводы: «по» / «от» / пара своих счетов

Правило владельца (парсер + очередь черновиков + шторка):

| Сигнал | Результат |
|--------|-----------|
| Только **«перевод по …»** (исходящий, в т.ч. «Перевод по СБП» без «от») | **Расход** (`purchase` → expense draft) |
| Только **«перевод от …»** (входящий) | **Доход** (`income` draft) |
| Есть **и** исходящий, **и** входящий с **той же суммой** и временем в окне пары (`draft-transfer`, ~2 ч) | **Перевод между своими счетами** (одна карточка пары → форма перевода) |

Пара собирается уже на уровне двух черновиков (expense + income), не внутри одного push. Одиночный push без зеркала остаётся расходом или доходом.

Не путать канал «по СБП» с игнором: голый `IGNORE` на `перевод по сбп` ломает и расход, и пары.

## Корневые причины

1. **Allowlist маркетплейсов целиком**  
   - WB: `com.wildberries.ru` (+ `ru.wildberries.fintech`) → `wbbank`  
   - Ozon: `ru.ozon.app.android` (+ `ru.ozon.fintech.finance`) → `ozon`  
   Маркетинг, доставка, распродажи проходят NLS так же, как «WB Кошелёк».

2. **`DraftNotifyProvisional`** (`InterceptPendingWake.onQueued`)  
   Показывает уведомление бухгалтера **до** JS-парса; `extractAmount` берёт первое число, валюта не обязательна → `80%` → `80 ₽`, `1256` → `125`, баланс вместо суммы перевода.

3. **Регрессия СБП (WB) + путаница «по»/«от»**  
   - `IGNORE_RE` глотал голый `перевод\s+по\s+сбп` → одиночный исходящий не становился расходом.  
   - Канал «по СБП» ошибочно смешивали с доходом; нужно: **«по» → expense**, **«от» → income**, пара expense+income → transfer.  
   Текст WB: `Перевод по СБП 500 ₽\nОльга…\nДоступно …` без зеркала → **purchase 500**; provisional мог показать `26867.01 ₽` (доступно).

## План работ

1. **Единый gate для шторки и черновиков**  
   - Provisional не показывать (или сразу снимать), если текст не прошёл бы `parseBankNotification`.  
   - Предпочтительно: шторка только после создания черновика (Accept/Reject), без «сырого» зеркала маркетинга.  
   - Если provisional оставляем — native amount **только** с маркером валюты; при parse=`null` — `cancel` этого id.

2. **Парсер (`parsers.ts`)**  
   - Убрать голый `перевод по сбп` из `IGNORE_RE`.  
   - «перевод по …» → purchase; «перевод от …» → income; сумму не брать из хвоста «Доступно/Баланс».  
   - Не принимать `%` как валюту; для marketplace-пакетов — строже (ключ операции / title «Кошелёк»/«Банк» / fintech-пакет).

3. **Пары (`draft-transfer`)** — без смены контракта: expense+income, одна сумма, окно времени → unique pair; иначе одиночный черновик.

4. **Allowlist (`banks.ts` + native store)**  
   - Предпочитать fintech-пакеты; для `com.wildberries.ru` / `ru.ozon.app.android` — доп. фильтр (title/text wallet/bank), иначе ignore.

5. **Тесты (максимально)**  
   - `parsers.test.ts`: A1 expense 500; A2 1256; solo «от» → income; B1–B7 → null.  
   - `draft-transfer.test.ts`: пара same amount/time; нет пары при одной стороне / разных суммах / вне окна.  
   - `draft-notify`: пара → один shade item; разные суммы → два item.  
   - Java `extractAmount` — только с валютой (provisional gate).

6. Docs: этот файл + короткое обновление [notification-intercept.md](notification-intercept.md); paired `.mdc` при правке `docs/`.
