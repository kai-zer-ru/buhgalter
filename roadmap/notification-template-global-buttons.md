# Глобальные кнопки в шаблоне уведомления

Патч **v1.9.2** к [кнопкам Telegram / MAX](telegram-max-buttons.md). Конструктор по-прежнему только на web.

## Зачем

«Кнопки по умолчанию» уходят в сообщение всегда первыми и в шаблоне их не видно. Порядок относительно кнопок шаблона поменять нельзя.

## Делаем

- В редакторе **каждого** шаблона (Telegram и MAX отдельно) глобальные кнопки этого канала уже стоят в раскладке.
- Они **всегда** есть в исходящем сообщении, пока заданы в блоке «Кнопки по умолчанию».
- В шаблоне их можно **перетаскивать** между рядами и внутри ряда. **Удалить нельзя.** Текст, тип и поля правятся только в «Кнопках по умолчанию» и сразу те же во всех шаблонах.
- Свои кнопки шаблона добавляются кнопкой «Добавить кнопку» (в том числе когда в раскладке пока только глобальные) и удаляются как сейчас.
- Новая глобальная кнопка, которой ещё нет в сохранённом порядке шаблона, встаёт **в конец** раскладки шаблона (перед зоной `balance_shortfall`, если она дописывается).
- Если своего порядка ещё нет — как раньше: сначала ряды global, потом ряды шаблона.
- Пустой URL после резолва по-прежнему выкидывает кнопку (это не удаление пользователем).

### Блок «Кнопки по умолчанию»

- Показывать конструктор только **включённого** канала: Telegram, если `telegram_enabled`, MAX, если `max_enabled`. Выключенный канал в этом блоке не рисовать. Клавиатуру выключенного канала при сохранении блока **не затирать**.
- Оба канала выключены — конструкторов нет (подсказка блока остаётся).
- Включён один — сразу его конструктор, без переключателя.
- Включены оба — переключатель **вкладками** (`PageTabs`: классы `.tab` / `.tab-active`, нижняя черта), не кнопками `btn-ghost`.

## Не делаем

- Копии глобальных кнопок внутрь JSON шаблона.
- Редактирование и удаление глобальной кнопки из карточки шаблона.
- Перестановку зоны `balance_shortfall`.
- Конструктор на Android и inbound/webhook.
