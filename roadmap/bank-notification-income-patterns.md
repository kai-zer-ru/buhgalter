# Улучшение парсера уведомлений: ВТБ «Поступление» и Сбер «Перевод по СБП» (SMS)

Статус: **реализовано** (v1.9.0). Пункт в [ROADMAP](../ROADMAP.md#v190).

## Контекст

Доработка эвристик перехвата — [notification-intercept.md](notification-intercept.md). На Android 15+ текст push мог подменяться заглушкой «Конфиденциальные данные скрыты» — обход для пользователя в [README](../README.md#банковские-push-конфиденциальные-данные-скрыты-android-15). После этого суммы снова видны; не хватало шаблонов для части **входящих** (ВТБ push, Сбер SMS СБП) — расширили JS-парсер (`parsers.ts`), не NLS/allowlist.

## Примеры с устройства

| # | Канал | Текст (сокр.) | Было | Стало |
|---|--------|---------------|------|-------|
| A | ВТБ push | `Списание 1000р Счет*1736 … Баланс …` | расход OK | регрессия OK |
| B | ВТБ push | `Поступление 1000р Счет*1736 от … Баланс …` | не операция | income |
| C | SMS 900 | `СЧЁТ5159 … Перевод по СБП … +1000р от …` | не операция | income + last4 `5159` |

Полные поля — в BMAD `fixtures.md`. Vitest — `parsers.test.ts`.

## Что поправили

1. `INCOME_RE`: `поступлен` + `перевод по сбп … от` (не любой «Перевод по СБП»).
2. Валютный gate / сумма: голый `р` рядом с цифрой (как `₽` / `руб` / `RUB`).
3. `LAST4_RE`: `СЧЁТ5159` / `Счет*1736` (счёт с/без `*`).
4. Чистый «Баланс…» по-прежнему `null` (`IGNORE_RE`); для income IGNORE не смотрится — достаточно income-ключа + валюты.
5. Подпись черновика: для income берётся контрагент после «от …»; заголовок «ВТБ Онлайн» не подставляется как merchant.
