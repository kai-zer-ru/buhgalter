# Экспорт без format — формат «Бухгалтер»

Патч **v1.9.2**. `GET /api/v1/export` без параметра `format` сейчас отдаёт CSV Cubux. Так написано в [docs/import/buhgalter.md](../docs/import/buhgalter.md) и в OpenAPI. Это ошибка контракта: без `format` должен выбираться внутренний формат «Бухгалтер».

---

## Делаем

- Нет параметра, пустая строка или одни пробелы — секционный CSV `#BUHGALTER,1` (полный перенос учёта).
- Фильтры `from`, `to`, `account_id`, `category_id` у этого формата по-прежнему игнорируются.
- Cubux — только явный `format=cubux` (регистр не важен).
- Неизвестное значение (`format=foo`) остаётся Cubux: опечатка не выгружает весь учёт.
- То же в `docs/import/buhgalter.md`, `docs/import/cubux.md` и OpenAPI. Пример Cubux с датами указывает `format=cubux`.
- Сборщик URL экспорта на web и Android при отсутствии `format` ведёт себя как «Бухгалтер»: фильтры в query не кладёт и ставит `format=buhgalter`.

В UI экспорта радиокнопка по умолчанию уже «Бухгалтер», и кнопка скачивания уже передаёт `format`. Экран не менять.

## Не делаем

- Пресет импорта без `preset` остаётся Cubux. Магия `#BUHGALTER` в файле не трогается.
- Фильтры дат для формата «Бухгалтер».
- CHANGELOG и release notes — только перед релизом версии.
